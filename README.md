# OpenWord

**▶ Try it live: [https://ccc321q.github.io/OpenWord/](https://ccc321q.github.io/OpenWord/)**

OpenWord is a free word processor that runs right in your web browser.
There is nothing to install and no account to create. Just open the link
above and start typing. Your documents stay on your own computer — nothing
is uploaded anywhere.

## What you can do

- Write and format text — bold, italic, colors, fonts, sizes, and styles
- Add tables, pictures, links, headers, footers, and page numbers
- Open Microsoft Word (`.docx`) files and save your work back as `.docx`
- Also open and save `.odt`, `.html`, and `.txt` files
- Move documents to and from Google Docs
- Autosave keeps your work safe in your browser while you type
- Find and replace words anywhere in the document
- Set up pages — Letter or A4, margins, portrait or landscape
- Print your document or save it as a PDF

## Try it

Open **[https://ccc321q.github.io/OpenWord/](https://ccc321q.github.io/OpenWord/)**
in any modern browser (Chrome, Firefox, Edge, or Safari). That's it.

## Run it on your own computer

1. Download or clone this repository.
2. Open the `index.html` file in your browser.

No build step, no server, no dependencies to install — it is a plain
website.

## How it's put together

| Folder | What's inside |
| --- | --- |
| `index.html` | The whole app in one page |
| `css/` | How everything looks, including print styles |
| `js/core/` | One small file per job — opening and saving files, autosave, menus, find and replace, and so on |
| `vendor/` | Two helper libraries (JSZip and DOMPurify) |
